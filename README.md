# 个人作品集网站 · Portfolio

> 计算机科学与技术专业 2026 届 · 用于求职的个人介绍网站（课程项目）

一个**纯静态**的个人作品集网站：HTML / CSS / JavaScript 手写实现，无框架、无构建步骤，
参考 [pudding.cool](https://pudding.cool/) 的编辑式排版与滚动动效风格，
手动部署到云服务器（Nginx），通过公网访问。

> 🚧 项目正在建设中，正式文档与页面内容持续补充中。

## 快速预览

无需安装任何依赖，两种方式任选：

1. 直接双击打开 `index.html`（或拖进浏览器）；
2. 在项目目录执行 `python -m http.server 8080`，访问 <http://localhost:8080>。

## 文档

所有项目文档使用 Markdown 撰写，位于 `docs/` 目录（详见后续提交）。

## 技术栈

- HTML5 / CSS3（CSS 变量、Grid、响应式）
- 原生 JavaScript（IntersectionObserver、requestAnimationFrame）
- Git 版本管理
- 阿里云 ECS + Nginx 手动部署

仅供学习与个人使用。
