## 十一、发布前自检

```bash
# 1. 找出所有 TODO 注释（应全部处理或确认保留原因）
grep -rn "TODO" index.html 404.html style.css main.js docs/ README.md

# 2. 找出所有占位文本
grep -rn "你的名字\|XX 大学\|yourname\|you@example.com\|示例" index.html 404.html

# 3. 检查外链资源（应为 0）
grep -rn "https\?://" index.html | grep -v "github.com\|mailto:"

# 4. 检查空链接（href="#" 的卡片需要替换成真实地址或删除）
grep -n 'href="#"' index.html

# 5. 本地最后预览
python -m http.server 8000
# 浏览器打开 http://localhost:8000，桌面 + 手机尺寸各走一遍
```
