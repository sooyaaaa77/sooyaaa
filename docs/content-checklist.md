## 十一、发布前自检

```bash
# 1. 找出所有 TODO 注释（应全部处理或确认保留原因）
grep -rn "TODO" index.html 404.html style.css main.js

# 2. 找出所有占位文本（应只剩校名与示例说明）
grep -rn "XX 大学\|示例\|yourname\|you@example.com" index.html 404.html

# 3. 检查外链资源（应为 0，除 GitHub / mailto）
grep -n "https\?://" index.html | grep -v "github.com\|mailto:"

# 4. 检查空链接（href="#" 的卡片需要替换成真实地址或删除）
grep -n 'href="#"' index.html

# 5. 旧版残留（跑马灯 / 自定义光标 / v0.2 色值，应为 0）
grep -nE "marquee|cursor-ring|data-cursor|f4efe4|1b1814|d64f2a" index.html style.css main.js

# 6. 本地最后预览
python -m http.server 8000
# 浏览器打开 http://localhost:8000，桌面 + 手机尺寸各走一遍
```
