# 02 · 技术设计与视觉规范

> 状态：v0.2（白底编辑风格改版） ｜ 最后更新：2026-11-10

## 1. 设计目标

参考 [pudding.cool](https://pudding.cool/) 的视觉语言，做一个**像编辑作品**的个人站点：

- 白底、黑字、彩色标签：干净、直接，信息密度靠排版而不是装饰堆砌
- 杂志式排版：大字号标题、强烈的字号对比、宽留白
- 滚动叙事：内容随滚动逐段出现，而不是一次性铺满
- 克制的动效：进场、悬停、跑马灯，不喧宾夺主；**不使用自定义光标**，保留系统默认鼠标
- 细节感：手写感红色波浪下划线、旋转星形、贴纸标签、彩色作品块
- 取舍：两周内**不做**自定义插画与数据可视化，改用 CSS 图形、内联 SVG 与系统字体替代

## 2. 技术选型

| 方案 | 结论 | 理由 |
|---|---|---|
| **纯静态 HTML / CSS / JS** | ✅ 采用 | 零构建、零依赖；部署 = 上传文件；与「手动部署」考核最匹配；出问题最好排查 |
| Vite + Vue 3 | ❌ 否决 | 需要 Node 构建、产物部署多一层变量；两周内调试成本高 |
| Astro / Next.js | ❌ 否决 | 概念多、构建链复杂，收益与风险不匹配 |
| GitHub Pages / Vercel / Netlify | ❌ 禁止 | 老师明确不允许托管服务，必须自己部署服务器 |
| 宝塔面板 / LNMP 一键包 / 应用镜像 | ❌ 禁止 | 要求手动装 Nginx、手动配置 |

**字体策略**：只用系统字体栈，不引入 Google Fonts 等外部资源，避免国内加载失败与首屏闪白。
标题用无衬线粗体（Helvetica Neue / PingFang SC / 微软雅黑），标签用等宽大写，正文用无衬线。

**图形策略**：装饰图形用内联 SVG 和 CSS（圆环、旋转星形、旋转方块、条纹），作品图先用彩色块占位，
后续替换为真实截图即可。

## 3. 信息架构

```
个人网站
├── 首屏 Hero            姓名、定位、CTA、滚动提示、装饰图形
├── 滚动横幅 Marquee     关键词循环滚动（深色条）
├── 01 关于我           自我介绍、引语、数字统计、照片占位
├── 02 教育经历         时间线、主修课程、方向
├── 03 技能栈           4 组标签
├── 04 项目经历         3 个项目卡片（浅灰交替区块）
├── 05 作品集           6 张彩色占位卡片
├── 06 联系我           邮箱、GitHub、简历
├── 页脚                 版权、说明、回到顶部
└── 404.html            错误页
```

单页锚点导航，不做多页；后续若加学习笔记再扩成多页。

## 5. 视觉规范

### 5.1 色板（CSS 变量，与 `style.css` 一致）

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--paper` | `#ffffff` | `#0f0f0f` | 页面底色 |
| `--paper-2` | `#f7f7f7` | `#191919` | 交替区块底色 |
| `--ink` | `#191919` | `#f2f2f2` | 主文字 / 反色块 |
| `--ink-2` | `#373737` | `#cacaca` | 次要文字 |
| `--muted` | `#6d6d6d` | `#a8a8a8` | 辅助信息 |
| `--faint` | `#a8a8a8` | `#6d6d6d` | 极弱信息（仅装饰/次要） |
| `--line` | `#dfdfdf` | `#333333` | 分隔线 |
| `--line-strong` | `#cacaca` | `#454545` | 强分隔线 |
| `--red` | `#ff533d` | 同 | 强调色：下划线、编号、贴纸 |
| `--yellow` | `#e5e338` | 同 | 关键词高亮、标签 |
| `--green` | `#3ae660` | 同 | 标签、作品块 |
| `--purple` | `#a239ca` | 同 | 标签、作品块 |
| `--blue` | `#4717f6` | 同 | 标签、作品块 |

对比度（WCAG AA 实测）：正文 17.58、次要 11.90、说明 5.17；黑字/黄 12.87、黑字/红 5.49、
白字/紫 5.28、白字/蓝 7.72；深色模式正文 17.12、说明 8.06。

### 5.2 字体与字号

- 标题/正文字体：`"Helvetica Neue", Helvetica, Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 等宽字体：`"SFMono-Regular", Menlo, Consolas, "Liberation Mono", "Courier New", monospace`（编号、标签、版本号）
- 字号阶梯（clamp 实现流体排版）：

| 层级 | 尺寸 |
|---|---|
| Hero 姓名 | `clamp(3.2rem, 11.5vw, 9.5rem)` |
| 区块标题 | `clamp(2.2rem, 5.2vw, 4.4rem)` |
| 项目标题 | `clamp(1.7rem, 3vw, 2.6rem)` |
| 正文 | `17px / 1.7` |
| 小标签 | `12px` + `letter-spacing: .16em` + uppercase |

### 5.3 间距与栅格

- 内容最大宽度 `1120px`，左右留白 `clamp(20px, 5vw, 48px)`
- 区块上下内边距 `clamp(80px, 11vw, 132px)`
- 圆角 `3–4px`（方正、贴纸感）；不用大圆角与胶囊按钮

### 5.4 动效参数

| 参数 | 值 |
|---|---|
| 快速反馈（悬停） | `.2s` |
| 常规过渡 | `.5s cubic-bezier(.2, .7, .2, 1)` |
| 进场动画 | `.9s`，位移 `26px`，逐级延迟 `.05–.35s` |
| 数字滚动 | `1200ms`，easeOutCubic |
| 装饰旋转 | 星形 48s 线性无限旋转；方块悬停旋转 |

## 6. 交互与动效清单

| 效果 | 实现方式 | 降级策略 |
|---|---|---|
| 区块进场 | IntersectionObserver 添加 `.is-in` | 无 JS 时默认显示 |
| 数字增长 | requestAnimationFrame | 减少动效时直接显示终值 |
| 滚动进度条 | scroll 事件计算百分比 | — |
| 跑马灯 | CSS animation `translateX(-50%)` | 悬停暂停 |
| 深色模式 | `[data-theme]` + localStorage | 不记忆也可用 |
| 移动端菜单 | 全屏遮罩 + class 切换 + 焦点陷阱 | 无 JS 时直接显示锚点 |
| 导航高亮 | IntersectionObserver 监听区块 | 不影响功能 |
| 自定义光标 | ❌ 已移除（v0.2 按用户要求恢复系统鼠标） | — |

所有交互基于原生 API，**不引入任何第三方库**。

## 8. 内容维护方式

- 文字内容直接写在 `index.html` 对应区块，占位内容有 `<!-- TODO: ... -->` 注释；
- 替换清单见 `docs/content-checklist.md`，逐项打勾；
- 换配色只改 `style.css` 顶部变量；换字体只改 `--font-*` 变量。

## 9. 性能 / SEO / 可访问性

- **性能**：无外链字体、无图片依赖（占位为 CSS 图形）；单文件 CSS/JS；只对 transform/opacity 做动画
- **SEO**：`<title>`、`description`、`og:*`、语义化 `header/main/section/footer`、单一 `h1`
- **可访问性**：skip link、`aria-*`、键盘可达、`:focus-visible`、移动菜单焦点陷阱、`prefers-reduced-motion`、对比度全部达 AA
