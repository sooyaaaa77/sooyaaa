# 01 · 需求分析

> 状态：v0.2（内容方向调整为 UE5 × 传媒交叉） ｜ 最后更新：2026-11-10
> 关联：`docs/02-design.md`（怎么实现）、`docs/03-plan.md`（什么时候做）

## 1. 背景与目标

课程要求制作一个个人介绍网站，同时作为大四毕业求职的作品集。核心目标不是展示开发能力，
而是完整地走一遍 **需求 → 设计 → 开发 → 版本管理 → 服务器部署 → 文档沉淀** 的工程流程。

- 交付物：一个可公网访问的个人网站 + 一套 Markdown 文档 + 一份可追溯的 Git 提交历史
- 成功标准：老师验收通过；网站能直接写进简历、发给 HR 查看

## 2. 干系人与使用场景

| 干系人 | 关心什么 | 使用场景 |
|---|---|---|
| 老师 | 流程是否完整、文档是否规范、部署是否真实完成 | 验收时查看站点、文档、Git 历史与服务器 |
| 未来雇主 / HR | 3–5 分钟内判断能力与匹配度 | 电脑或手机打开、快速浏览、下载简历 |
| 自己 | 长期可维护、内容可持续更新 | 每学期补充项目与作品 |

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首屏 ≤ 1.5s（3M 带宽）；无外部字体/图片依赖；Lighthouse 性能 ≥ 90 |
| 响应式 | 360 / 768 / 1024 / 1440 / 1920 五档检查 |
| 可访问性 | 语义化标签、键盘可操作、skip link、对比度 ≥ 4.5:1、尊重 `prefers-reduced-motion` |
| 安全 | 服务器只开 22/80/443；SSH 密钥登录；仓库不出现密码、私钥、服务器地址以外的敏感信息 |
| 可维护性 | 纯静态、无构建、内容与样式分离，改文字不需改样式 |
| 成本 | 阿里云学生认证 300 元代金券覆盖服务器费用，域名暂不购买 |

## 6. 硬性约束

| 约束 | 对方案的影响 |
|---|---|
| 所有文档必须用 Markdown | 文档统一放 `docs/`，图片放 `docs/assets/` |
| 必须用 Git 管理并记录关键提交 | 采用 Conventional Commits；每次提交只做一件事；提交记录整理进 `docs/05-git-record.md` |
| 必须部署到云服务器并公网访问 | 阿里云 ECS + 手动安装配置 Nginx（见 `docs/04-deployment.md`） |
| 禁止：宝塔等面板、LNMP/LAMP 一键包、云厂商应用镜像、GitHub/Gitee Pages、Vercel、Netlify | 只能用**系统镜像 + 手动命令**部署，因此采用纯静态站 + 手动 Nginx |
| 周期两周 | 范围必须收敛，第 5 天前完成首次上线 |
| 阿里云学生认证 300 元券，暂无服务器和域名 | 只买一台轻量服务器；不买域名，用 IP 访问（域名+备案列为可选扩展） |
| 允许 AI 辅助 | 用 AI 提效，但需人工审核，过程记录进 `docs/06-ai-usage.md` |

## 7. 范围外（本期不做）

后端 API、数据库、登录注册、留言板、在线编辑器、多语言、支付；
自定义域名与 HTTPS（时间不够，作为可选扩展）；
访问统计（可选，不影响验收）。

## 8. 假设与依赖

- 阿里云学生认证可正常完成并能使用 300 元券购买 1 台服务器；
- 大陆地域服务器即使不备案，也能通过公网 IP 的 80 端口访问（无域名）；
- 老师验收可接受「IP 访问 + 文档说明未做域名」这一形态（第 1 周内确认）；
- 真实素材可能在开发过程中陆续补充，先以示例内容跑通。

## 9. 验收标准（Definition of Done）

- [ ] 公网 IP 可在手机 4G 网络打开
- [ ] 全部区块替换为真实信息，无示例残留
- [ ] 桌面与移动端布局正常、无横向滚动条
- [ ] 文档 01–08 齐全，全部为 Markdown
- [ ] Git 历史 ≥ 10 次有意义提交，含 `v0.1.0` / `v1.0.0` tag
- [ ] 按 `docs/04-deployment.md` 可从零复现部署
- [ ] Lighthouse：性能 ≥ 90、可访问性 ≥ 90
- [ ] 控制台无报错、无死链

## 10. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 两周时间紧，内容与开发互相挤占 | 高 | 高 | 收敛范围；D5 前必须上线；作品集可降级 |
| 真实素材迟迟不到位 | 高 | 中 | 示例占位 + 素材清单驱动，D8 前必须替换 |
| 服务器购买/认证受阻 | 中 | 高 | D2 就开始买；实在不行用学校服务器或本地录屏兜底 |
| 代金券适用范围受限（地域/机型） | 中 | 中 | 购买前先看券的说明，选可抵扣的地域与机型 |
| 动效过多导致手机卡顿 | 中 | 低 | 只用 transform/opacity；`prefers-reduced-motion` 降级 |
| 备案来不及 | 高 | 低 | 不买域名，直接用 IP 访问 |
